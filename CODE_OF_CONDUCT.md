# Code of Conduct

IraqCode is committed to a learning environment where contributors and learners are treated with respect. Harassment, discriminatory language, personal attacks, doxxing, threats, and deliberately disruptive behavior are not acceptable.

Give feedback about code and content constructively. Challenge ideas rather than people, respect different experience levels, and make room for Arabic and English communication styles.

Project maintainers may remove content, comments, issues, or contributions that violate these standards. To report a concern privately, follow the contact process in [SECURITY.md](SECURITY.md).
