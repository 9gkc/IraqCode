# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do **not** disclose security vulnerabilities in public issues. Use GitHub’s private security-advisory reporting flow for this repository, describe the impact and reproduction steps safely, and allow reasonable time for assessment and remediation.

IraqCode is a static educational application. Reports involving third-party services, browser extensions, or unrelated GitHub infrastructure should be directed to the relevant owner.
